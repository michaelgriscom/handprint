# Fonts

Both families are licensed under the SIL Open Font License 1.1 and are vendored
here (Latin subsets, woff2) so the tracker renders the same everywhere, with no
third-party font requests.

- **Newsreader** - Production Type for Google Fonts. https://github.com/productiontype/Newsreader
  (`newsreader-latin.woff2`, `newsreader-latin-italic.woff2`: variable weight 200-800)
- **Young Serif** - Bastien Sozoo. https://github.com/noirblancrouge/YoungSerif
  (`young-serif.woff2`)
